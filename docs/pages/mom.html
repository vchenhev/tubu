本章仅适用于配置为 zhgy6c 或 zhgy8c 的设备，不适用于通用 MES。两种现场使用相同的取参、开检、上传及服务器连接规则。

zhgy6c / zhgy8c

现场名称为 zhgy6c 或 zhgy8c 时，均使用“MES 配置”中的“zhgy6c / zhgy8c”页面，读取同一套已有 MOM 配置，维护启用状态、厂部、数据类型、上传频率（完整批次数）、超时秒数和七项接口的完整地址。设备编号自动读取主程序已有的本机配置，在此只读显示，每台电脑使用自己的编号。厂部默认“6部”，可以按现场 MOM 要求修改；已有非空厂部配置继续保留。仅上传本机启用的尺寸、错位数据。修改配置前先停止检测；各接口地址需与现场 MOM 服务一致。接口开关独立，关闭某项仅停止该项请求，不清除同一设备、现场、料号和膜卷号下仍有效的员工、工单和批次。超时、上传频率、厂部、数据类型变化不清空这些信息；人员地址变化只要求重新取得员工身份，参数地址变化只要求重新获取工单和批次，换型完成或生产开始地址变化重置对应接口结果。设备、现场或 MES 总开关变化会清理生产信息。本地检测标准保留，执行结果区持续显示当前生产信息是否就绪。

桌面窗口中，页面上方左侧为七项接口表格，右侧为等高的服务器连接面板；第二行左侧为运行参数，右侧为等高的生产完工面板。“测试连接”和“MOM 生产完工”分别位于对应面板标题右侧。设备编号、厂部、数据类型、上传频率和超时使用紧凑输入框，空间不足时自动换行。下方左侧为接口测试，测试卡号位于按钮上方，测试按钮按两列排列；右侧并排显示请求与返回报文，长报文在编辑框内滚动。底部执行结果区显示当前接口、网络、HTTP、业务结果、生产信息及执行详情，可点击“查看运行日志”查看历史记录。点击接口行可切换查看该项结果；窄窗口下配置和诊断区域依次上下排列，报文阅读宽度不足时也改为上下显示。按钮尺寸统一，并随软件明暗主题切换。七项接口分别勾选启用，修改后点击“保存配置”生效。关闭某项后跳过对应调用：人员资质校验关闭时仍按本地卡号查找用户及角色；参数请求关闭时保留当前料号；生产开始、结束关闭时跳过相应 MOM 通知；上传和人员操作日志关闭时停止对应发送。接口仍启用时，MOM 拒绝或网络失败继续按原规则处理。

生产字段与接口开关

3“产品参数请求”和6“工序参数上传”可分别启用。仅取参时不要求启用上传；MOM 缺少上传所需生产字段时，正常关联参数仍可应用，缺项由上传单独检查。关闭取参后，上传可沿用当前设备、现场、料号和膜卷号下已取得的有效 MOM 生产信息，测量值和公差采用本机实际检测参数，编码采用该生产信息固定的上传模式和映射。没有有效生产信息、换卷后尚未取得新批次信息或保存映射、切换上传模式使缓存失效时，只继续本地检测，不上传。参数编码映射不能代替 MOM 工号、工单、型号、工序、料号和批次，软件不会用本地料号名或卷号猜测这些字段。

工序参数上传按当前真实工号、工单、型号、工序、料号、批次、厂部和数据类型逐项检查。缺项时只跳过本次上传并列出字段，不影响其它接口，不使用卡号代替工号，也不编造生产字段。两种现场的换型完成、生产开始均按各自开关调用，返回 NG、HTTP 错误或超时时保留失败结果并提示，允许继续本地检测；一项失败后仍处理另一项。工序参数上传独立检查真实字段、当前设备、现场、料号和膜卷号归属及测量数据，不要求这两项通知成功，由 MOM 返回上传业务结果。通知失败不表示上传成功；MOM 拒绝上传时记录失败并继续处理后续数据。关闭人员或参数请求后，可继续使用同归属下已取得的有效字段；重启、来源变化或换卷后缺少数据时仍须从对应接口重新取得。人员接口关闭时，本地刷卡仍需匹配已有本地卡号及角色，不会新增 MOM 身份。单接口配置变化只重置该接口结果和在途请求，上传或日志地址变化不清空工单。

服务器连接与状态

两种现场的服务器 IP、端口均从已保存且启用的接口完整地址读取，只读显示；修改接口地址后需保存。软件启动、启用 MOM 或保存配置后立即检查，之后每 10 秒自动复查；每个目标最长检测 3 秒，不阻塞界面。同一主机、同一端口只检查一次，多个目标并行检测，全部可达才表示正常。点击“测试连接”立即执行同一检查，与当前选中接口无关；页面列出各目标结果和最近完成时间。检测只建立 TCP 连接，不发送 HTTP、人员校验或生产报文，也不恢复上次生产会话；重启或生产归属配置变化后需正式刷卡再开始生产。未写端口的 HTTP 地址使用 80，HTTPS 使用 443。

两种现场均需分别查看网络、HTTP 和业务结果；端口可达不代表接口路径、人员资质、工单或上传成功。

接口测试与请求返回

填写测试卡号后可执行“刷卡验证测试”：直接请求 MOM，检查返回工号、姓名及权限等级，再按等级匹配本地角色，无需登记本地用户；只显示验证结果，不建立登录会话、不缓存生产员工身份，正式生产前仍需在主界面刷卡。“参数查询预览”只显示返回公差，不覆盖料号、不执行换型或办理生产开始。选中七项接口中的任意一项后，可在“请求报文”中编辑 JSON，点击“测试当前接口”只向选中地址发送一次请求；停用接口保持选中状态并显示“接口未启用”，不发送请求。人员、参数、换型、生产开始、上传、生产结束和操作日志分别保留各自的请求与返回结果。测试和保存均使用现有权限确认；刷卡及参数测试读取已保存接口配置，两种现场的服务器 TCP 检测均读取已保存且启用的接口地址。生产开始、参数上传和生产结束测试会影响 MOM 真实业务状态，测试前必须确认设备、工单、批次和员工工号。

两个现场的工序参数上传测试会在编辑报文时列出缺少的必填字段、批次和测量参数；缺项仅提示，仍可点击“测试当前接口”按原文发送，由 MOM 返回校验结果。此测试不补齐字段，也不建立正式员工、工单或生产信息。需要发送当前完整业务数据时，使用“手动上传最新一笔”。

自动上传和“手动上传最新一笔”均按已保存的上传模式、映射及当前完整检测结果正式组包，不读取请求编辑框中的测试草稿。修改请求框不会改变正式上传；勾选“上传固定使用通用映射（按已保存配置）”也不会重写测试草稿。“测试当前接口”仍发送请求框中的 JSON 原文，不能据此判断正式上传映射是否生效。

“执行结果”区的“查看运行日志”打开现有软件日志目录，可按日期查看：Debug 保存实际 MOM 请求和返回，Error 保存异常、超时及技术告警，Records 保存刷卡认证和人员操作。页面的执行结果是当前接口最近一次记录，不能代替历史日志；两种现场的 TCP 检测结果均同时更新页面和底灯。

两种现场的底灯绿灯均表示“MOM服务器端口可达”，仅在全部启用目标均可达时点亮；任一目标失败显示红色“MOM服务器端口不可达”，地址或配置异常显示红色“MOM服务器配置异常”。首次检测短暂显示灰色“MOM服务器检查中”，没有启用接口时显示灰色“MOM接口未启用”；周期复查期间保留上次结果，避免闪灯。网络恢复后自动更新，后台检测失败不反复弹窗。HTTP 错误、MOM 业务拒绝及本地参数校验失败仍查看对应接口；服务器端口状态独立于业务通信记录及 PLC 蓝灯控制。

参数编码映射配置

入口为“MES 配置 → zhgy6c / zhgy8c → 运行参数”面板内、“超时（秒）”右侧的小按钮“参数编码映射配置”。两个现场共用一份配置，包含通用映射和负极映射。名称取自现有尺寸、错位名称配置；名称变化不改变关联。本节图片中的名称、数值和状态仅供阅读参考。

  1. 停止检测，打开“参数编码映射配置”。表格显示映射类别、本地 WidthCode / OffCode、对应名称、MOM 参数编码和启用状态；表格中的类别、本地编码和名称只读。
  2. 在窗口顶部标题右侧、与“参数查询预览”“保存配置”同排的“上传固定使用通用映射（按已保存配置）”中设置上传模式，默认不勾选。勾选状态与表格内容均为页面草稿，只有成功保存后生效。
  3. 新增时先选择“通用映射”或“负极映射”，按编码或名称检索本机可见测量项，从候选中选择，在右侧“MOM 参数编码”输入框填写经现场确认的编码后点击“新增映射”。名称和 MOM 编码一起带入表格，表格中的 MOM 编码仍可编辑；不创建本地编码或测量工具。同类别下的本地关联不能重复。需要删除时选中行并点击“删除映射”；暂时不用也可取消启用。
  4. 点击“参数查询预览”，按现有权限确认后查询已保存的参数接口，对照返回编码、名称、单位、目标值和上下限。预览仅查询，不覆盖检测标准、不建立生产信息，也不上传测量数据。缺少上下限的返回不会补零。
  5. 经现场确认关联后，编辑条目的 MOM 编码。预览返回的 A0245、M0776 等编码不能仅按名称、顺序或相近数值推断对应测量项。删除或停用的条目不参与取参关联及上传，不回退到默认编码。
  6. 停止检测后点击本窗口的“保存配置”，通过现有 MOM 保存权限确认，一起保存上传模式与映射草稿。启用项编码为空、同一本地关联重复、上传编码重复，或通用与负极映射共用编码造成识别歧义时拒绝保存，提示具体类别及本地编码。写入失败保留原文件和当前生效配置；配置文件损坏时提示原因并保留原文件，先核对内容后重试。

勾选始终使用本机已保存、启用的通用映射。即使 MOM 返回负极编码，上传也不切换到负极映射。

“固定”只固定上传映射类别。修改通用映射中的 MOM 编码，或新增、删除、启用、停用条目，成功保存并重新建立有效生产信息后仍会影响上传。正式上传只筛选当前完整检测批次中本机测量已启用、数据来源符合要求、有有效结果且存在启用映射的项目，不直接发送通用表全部条目。删除、停用或未配置的通用条目不上传，不回退到负极映射、内置编码或 NG 编码；没有可上传项目时跳过并提示原因，不生成空参数报文。

此勾选项不关闭、跳过或削弱接口3。接口3继续按 MOM 返回识别通用或负极、匹配本机标准，保留单位检查、上下限校验、异常二次确认和失败容错，并解析、保存真实批次号、型号、工单、工序及产品编号。勾选后允许取参与上传使用不同类别，以相同的本地 WidthCode / OffCode 关联。例如，APolarEar1 通过负极映射匹配 A20274 取得标准，而现场已将其通用映射配置为 A20304，则上传使用 A20304；这只是关联说明，示例编码不会自动填入配置。上传值、标准、上下限、判定和时间仍来自原有真实检测结果，生产信息仍来自同一有效上下文。

映射内容或上传模式修改并成功保存后，相关参数、生产缓存及旧检测结果的上传资格立即失效，检测标准仍保留。须按既有准入流程重新建立完整、有效的生产信息，并产生新的完整检测结果后再上传；不能用新模式重新编码旧结果。修改前尚未完成的取参返回和排队上传报文失效，已发出的请求仍按原请求归属记录。普通 MOM 配置保存保留已保存模式和映射；本窗口保存也保留接口地址、接口开关等配置。接口3关闭时不因本勾选项强制发送取参请求，现有有效信息复用及缺项不上传规则仍适用。

负极识别仍按返回编码判断，但只使用当前启用的负极映射编码；停用项不参与识别和下发，也不回退到默认编码。同一批取参按通用或负极一种模式匹配，不混合使用两类映射；正式上传类别另按上表的已保存模式确定。本地 WidthCode / OffCode、NG 编码、尺寸计算及检测判定含义不变，生产信息不完整时不上传。

关联参数异常与确认

正式取参先按本次启用映射筛选，再校验与本机测量项关联的参数。未关联的面密度、增重、测厚等参数不影响 CCD 标准下发；例如 A6188 未配置关联时会被忽略。若现场将某编码明确配置为本机测量项，则按该关联参与校验，不能仅凭编码名称跳过。

相关参数出现标准值或上下限缺失、非数字、上下限关系无效、同编码工站返回冲突等异常时，异常项保留本机原标准，正常项仍可应用；缺失值不会补零。两种现场均校验相关参数单位：单位非空时必须为 mm，软件不进行单位换算，单位不符的条目同样保留本地标准并提示确认。软件列出异常编码、名称、MOM 标准值及上下限和对应本地标准，提示继续检测可能影响 OK/NG 判定、造成漏检或误判，须核对后明确确认继续。取消确认时不应用本次参数。确认选择和具体异常记录在运行日志中，不能把人工确认视为 MOM 参数正确或上传成功。

取参、开检与正式登录

两种现场在启用 MES 及产品参数请求后，均在开启软件及实际换卷时获取 MOM 产品参数，保存匹配且有效的测量项标准值和上下限；同一膜卷号重复读取不重复获取。取参无需提前刷卡，不办理换型或生产开始。关联参数异常时按上节核对并确认，异常项保留本地标准；网络失败、全部未匹配或保存失败时提示原因，保留原有标准值、上下限及预警设置，允许检测继续。修正后可在“参数查询预览”复核，再重新开始检测，在参数信息缺失或归属变化时补取。预览只查看返回，不应用参数。运行中换卷取参期间继续使用旧参数，成功保存后采用新值；过期料号或旧卷的返回不会应用到当前卷。

两种现场手动开始时，已有参数信息属于当前设备、现场、料号和膜卷号则复用缓存；信息缺失、归属变化，或启用上传但缓存缺少工单等取参生产字段时，在参数请求启用的前提下重新获取并应用参数，再调用已启用的换型完成和生产开始接口。参数请求关闭时不补取。补取失败时保留本地检测标准，缺少完整生产信息时不上传；换型或生产开始失败时提示“允许继续本地检测”，对应失败原因和原始报文保留在接口结果中。缺少 MOM 工号时跳过需要工号的通知和上传，允许本地检测，须正式刷卡补齐身份；人员登录认证本身仍按原规则校验。两种现场点击“停止”均直接执行本地停检，不请求 MOM 生产结束，也不因 MOM 拒绝、超时或员工信息缺失而取消停检。人员权限异常应核对员工状态与设备授权；缺工单或批次需核对参数接口及其返回字段。两个现场均不将新设备、料号或膜卷号的数据上传到旧工单、旧批次。网络错误先测试端口，再查看 HTTP 和业务返回。

人员资质校验启用时，刷卡后直接将原始卡号和设备编号发送到 MOM，无需预先建立本地用户。MOM 返回成功且包含员工工号、姓名和权限等级时，按该等级匹配本地角色 ID，加载该角色配置的功能权限，并以 MOM 返回的姓名登录；不会新增或修改本地用户。当前接口字段为 EmployeeNo、EmployeeName 和 Permission。返回缺项、等级没有对应本地角色、MOM 拒绝或请求超时均不允许本次刷卡登录，也不回退到本地卡号绕过验证。保存前确认仍需使用同一卡号重新请求 MOM，可再次刷卡或手动输入；返回身份或等级变化时须重新登录。人员接口关闭时保留原有本地卡号及角色验证；原有密码登录和启动自动登录方式保留。生产及操作日志接口使用正式刷卡返回的 MOM 员工工号。

现场为 zhgy6c 或 zhgy8c 且人员资质校验接口启用时，从主界面打开登录窗口，只显示“MOM 卡号”输入框和居中的“登录”“取消”按钮，登录名、密码及独立的“MOM验证”按钮不显示。在“MOM 卡号”中填写并点击“登录”或按回车，软件将卡号和本机设备编号发送到人员资质校验接口；该入口建立正式登录会话，可供生产及操作日志使用。返回身份、权限及失败处理与正式刷卡一致，也可直接刷卡。人员接口关闭后恢复原账号密码登录界面，不修改已保存的登录方式配置；保存前确认仍按当前账号的认证方式执行，MOM 身份可输入同一卡号后点击“确认”。配置页“刷卡验证测试”仍只供测试，不建立生产登录会话。

  1. 启用 MES 和产品参数请求后，两种现场均在开启软件及实际换卷时获取参数；手动点击“开始”按上文复用缓存或补取，再执行已启用的换型完成查询和生产开始。取参失败时提示原因，沿用本地标准检测，缺少完整生产信息时不上传；换型完成或生产开始失败同样允许继续本地检测。保存配置使生产信息失效后，正式刷卡并重新开始可重新取得。
  2. 下发参数按本地尺寸 WidthCode、错位 OffCode 对应的当前启用 MOM 映射匹配本机启用项。正常项直接覆盖标准值和上下限，不要求与本地旧值相同；相关异常项经确认后保留本地原值。上传使用本次有效生产信息固定的上传模式、对应类别映射及实际生效的测量公差，不读取或改写料号原有 NG 编码；名称改动不影响编码匹配。未匹配项及其它参数保留。两厂网络取参失败、全部未匹配或保存失败时均提示原因，允许沿用本地标准检测；失败请求中的工单和批次不用于建立生产信息，缺少完整信息时不上传。已成功保存的参数在后续换型或生产校验失败时仍保留。
  3. 过程参数按现有 MES 笔数频率上传，报文保留本次生产的工单、批次和正式刷卡取得的 MOM 员工工号；界面自动注销不改变已开始生产的数据归属。判定 WARN 按 OK 上传；上传失败记录原始请求、返回和原因，继续处理后续数据，不自动补传。
  4. 点击“手动上传最新一笔”，立即发送当前料号和膜卷最近一笔完整检测结果，不受上传频率限制，也不改变自动上传的计数；每次点击发送一次，自动上传继续执行。该入口与自动上传遵守相同的已保存上传模式和正式组包规则，不使用请求框的测试草稿。MES 总开关、工序参数上传接口及 MOM 真实生产字段、归属和编码校验仍须通过；两种现场均不要求换型完成、生产开始成功。局部相机结果不能用于此操作；换料号、换卷、修改映射、切换上传模式或清理运行数据后，须先按既有流程恢复有效生产信息并产生新的完整结果。执行结果和请求、返回报文在工序参数上传接口中查看；失败保留原因，不自动重试。
  5. 批次实际完工时，先停止检测，再到“MES 配置 → zhgy6c / zhgy8c → 生产完工”点击“MOM 生产完工”。需启用 MES 和生产结束接口，并使用仍有效的正式 MOM 员工身份，通过现有 MES 操作权限确认。运行中不能办理完工；完工请求处理中不能同时重新开工。MOM 返回 NG、超时或请求异常时显示原因，本地检测保持停止；超时后先核对 MOM 实际批次状态。完工成功后不再上传该次生产的数据，后续重新运行时按原开工流程建立生产信息。仅临时暂停检测时无需提交完工；本地设备停止失败仍按实际提示排查。
